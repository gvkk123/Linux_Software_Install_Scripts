Updating Anaconda after installing Miniconda as a User in order below:
 
conda update conda
conda update -n base -c defaults conda

conda update --all
##############################################
Adding CondaForge has higher priority channel:

conda config --show-sources
conda config --add channels conda-forge
conda config --set channel_priority strict

##############################################
