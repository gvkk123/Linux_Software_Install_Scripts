

https://www.itzgeek.com/post/how-to-install-eclipse-ide-on-ubuntu-20-04/

Download the Eclipse  Package from Website:

sudo apt install default-jdk default-jre
java -version


Extract to OPT folder:
sudo tar -zxvf eclipse-embedcpp-2026-03-R-linux-gtk-x86_64.tar.tgz -C /opt/


sudo ln -sf /opt/eclipse/eclipse /usr/bin/eclipse


Create Application Shortcut:
sudo nano /usr/share/applications/eclipse.desktop


[Desktop Entry]
Encoding=UTF-8
Name=Eclipse IDE
Comment=Eclipse IDE
Exec=/usr/bin/eclipse
Icon=/opt/eclipse/icon.xpm
Terminal=false
Type=Application
StartupNotify=false




Copy Shortcut to Desktop:
sudo cp /usr/share/applications/eclipse.desktop ~/Desktop/
